# Simulasi Energi Gedung di Superkomputer (HPC)

Mensimulasikan total konsumsi listrik gedung kampus akibat penggunaan AC menggunakan *Agent-Based Simulation* dengan *scheduler* SLURM.

## Struktur
- `code/`: Kode sumber Python.
- `run.sh`: Job script SLURM untuk *cluster* HPC.
- `results/`: Output JSON dan grafik hasil komputasi.
